# 每日選片流程（排程任務每天清晨執行）

目標：替四個級別各選 **一部** 新的中文故事影片，寫好 3 個問題，更新 `daily.json`，推送到 GitHub。網頁會自動顯示新影片。

## 0. 準備

- 在 repo 根目錄工作。今天的日期以 **Asia/Bangkok** 時區為準（`TZ=Asia/Bangkok date +%F`）。
- 讀 `daily.json`（最新的一天在最前面）和 `used.json`（用過的影片 ID）。
- 如果 `daily.json` 最新一天已經是今天：不要重做，直接結束並回報「今天已更新」。

## 1. 搜尋候選影片

用 WebSearch，**限定 `allowed_domains: ["youtube.com"]`**，只採用 `youtube.com/watch?v=` 的網址（11 碼 ID）。每個級別至少搜 2～3 個不同的關鍵字，從下面輪替使用（依日期換著用，避免每天搜一樣的）：

| 級別 | 代號 | 搜尋關鍵字範例 |
|---|---|---|
| 幼兒園 | `k` | 有聲繪本 睡前故事、兒童繪本故事 中文、佳佳老師說故事、幼兒 品格繪本、晚安故事 動畫 |
| 國小 1–3 | `p1` | 伊索寓言 中文 動畫、成語故事 動畫 兒童、童話故事 中文、momo 成語故事、寓言故事 小學 |
| 國小 4–6 | `p2` | 成語典故 動畫、看動畫學歷史 普通話、中華歷史故事 動畫、寓言故事合集、神話故事 動畫 |
| 中學 1–3 | `m` | 成語任務 中華文化永續發展基金會、世說新語 故事、史記 故事 動畫、春秋戰國 歷史動畫、古文 故事 動畫 |

## 2. 篩選規則（全部都要符合）

1. **普通話**：標題或說明出現「粵語」「廣東話」「Cantonese」「台語」的一律排除。
2. **適合孩子**：不選恐怖、暴力、驚悚、廣告開箱、遊戲實況、Shorts（`/shorts/`）、直播。
3. **不重複**：ID 不在 `used.json`，也不在 `daily.json` 任何一天。
4. **片長**：能看出片長時，幼兒園 3–10 分鐘、國小 3–15 分鐘、中學 5–20 分鐘；超過 30 分鐘的合輯不選。
5. **優先可信頻道**：佳佳老師說故事、格子酱讲绘本、碰碰狐、洪恩、momokids 親子台、FOOD超人、香港教育大學中文動畫系列（只選普通話版）、FCCSD 中華文化永續發展基金會、Harvest Culture 百禾文化。其他頻道也可以，但標題和說明要明確是兒童教育內容。
6. **內容可以出題**：選標題或說明能看出故事內容的影片（例如經典寓言、成語、繪本書名、歷史人物）。說明太少、看不出在講什麼的不選。

## 3. 分級標準

| 級別 | 語速（字／分鐘） | 主題與片長 |
|---|---|---|
| 幼兒園 | 100–120，語氣柔和、停頓多 | 繪本動畫、生活習慣、情緒故事；短片 |
| 國小 1–3 | 120–140 | 伊索寓言、簡單成語、童話 |
| 國小 4–6 | 120–140 | 寓言、成語典故、歷史人物 |
| 中學 1–3 | 140–180 | 成語出處、經典寓言、古文與歷史故事 |

目前無法測量實際語速，依主題、用詞難度、目標年齡（說明裡的「適讀年齡」）與片長判斷級別。

## 4. 每部影片要寫的資料

```json
{
  "id": "11碼影片ID",
  "title": "影片標題（可精簡，去掉 hashtag 和重複的分隔詞）",
  "channel": "頻道名稱",
  "topic": "主題・重點（例：寓言・誠實）",
  "dur": "約 6 分鐘（不知道就不要寫這個欄位）",
  "why": "一句話說明為什麼適合這個年級，給家長看",
  "quiz": [ 3 題，見下 ]
}
```

### 三個問題（quiz）

- **剛好 3 題**，用孩子聽得懂的語氣，題目要短。幼兒園題目更簡單（是誰、在哪裡、什麼東西）。
- 前 1–2 題是 **fact 題**（有答案），最後至少 1 題是 **open 題**（說自己的想法或經驗）。
- **fact 題只問能從標題、說明或該經典故事本身確定的內容**。不確定影片怎麼演，就改出 open 題。不要編造影片細節。
- fact 題格式：
  ```json
  {"type":"fact","q":"烏鴉把什麼東西放進瓶子裡？","keywords":["石頭","小石頭","石子"],
   "answer":"烏鴉把小石頭一顆一顆放進瓶子裡，水就變高了。","hint":"地上撿得到的，硬硬的東西。"}
  ```
  `keywords`：孩子答案裡只要出現其中一個就算對。多放同義詞、口語說法、繁簡兩種寫法；不要放「的」「是」這類太常見的字。
- open 題格式：
  ```json
  {"type":"open","q":"你遇到困難時會怎麼想辦法？","sample":"我的球卡在樹上，我用竹竿把它弄下來。","praise":"你也是會動腦的小聰明！"}
  ```
- 全部使用**繁體中文**。

## 5. 寫入檔案

1. 在 `daily.json` 的 `days` 最前面插入今天：`{"date":"YYYY-MM-DD","picks":{"k":{…},"p1":{…},"p2":{…},"m":{…}}}`。
2. `updated` 改成今天日期。`days` 只保留最新 **14 天**。
3. 把今天四部影片的 ID 加進 `used.json`（保持排序、不重複）。
4. 執行 `python3 scripts/validate.py`，有錯就修到通過為止。

## 6. 推送

```
git add daily.json used.json
git commit -m "Daily picks YYYY-MM-DD"
git push origin main
```

推送失敗時：`git pull --rebase origin main` 後再推一次。

## 7. 回報

用一則簡短訊息回報：今天四個級別各選了哪部影片（標題＋頻道），以及網址 https://chineseteachingtool.github.io/daily-story/ 。找不到合格影片的級別要說明原因（那個級別可以沿用昨天的影片，但 `why` 要註明「今日沿用」）。
