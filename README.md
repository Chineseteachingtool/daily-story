# 每日故事屋

每天依年級挑選一部適合孩子的中文故事影片，家長點開就能讓孩子看。

- 網址：https://chineseteachingtool.github.io/daily-story/
- 級別：幼兒園／國小 1–3／國小 4–6／中學 1–3
- 功能：播放速度調整（0.5x–1.5x）、中文／英文字幕切換、看完打勾

## 分級標準

| 級別 | 語速（字／分鐘） | 主題 |
|---|---|---|
| 幼兒園 | 100–120，語氣柔和、停頓較多 | 繪本動畫、生活習慣、情緒故事 |
| 國小 1–3 | 120–140 | 伊索寓言、簡單成語故事、童話 |
| 國小 4–6 | 120–140 | 寓言、成語典故、歷史人物 |
| 中學 1–3 | 140–180 | 成語出處、經典寓言、歷史故事 |

## 在自己電腦離線使用

Windows：雙擊 `start-story.bat`（直接開啟 index.html 時 YouTube 會拒絕播放）。

## 狀態

原型版本：影片目前由人工挑選，之後由 skill 每天產生影片清單。
