# 每日故事屋

每天依年級挑選一部適合孩子的中文故事影片，家長點開就能讓孩子看。

- 網址：https://chineseteachingtool.github.io/daily-story/
- 級別：幼兒園／國小 1–3／國小 4–6／中學 1–3
- 功能：播放速度調整（0.5x–1.5x）、中文／英文／中英字幕、看完打勾
- 即時字幕：影片沒有字幕軌時，按「🎙 即時字幕」，用麥克風聽喇叭聲音辨識中文並翻譯成英文（需 Chrome 或 Edge、喇叭外放）
- 看完問答：影片播完（或按「看完了」）會出 3 個問題，孩子可以打字或按 🎤 用說的回答，網頁會回應並給星星
- 字幕檔：放入 `subs/<影片ID>.json`（格式 `[{"s":秒,"e":秒,"zh":"…","en":"…"}]`）會優先使用

## 分級標準

| 級別 | 語速（字／分鐘） | 主題 |
|---|---|---|
| 幼兒園 | 100–120，語氣柔和、停頓較多 | 繪本動畫、生活習慣、情緒故事 |
| 國小 1–3 | 120–140 | 伊索寓言、簡單成語故事、童話 |
| 國小 4–6 | 120–140 | 寓言、成語典故、歷史人物 |
| 中學 1–3 | 140–180 | 成語出處、經典寓言、歷史故事 |

## 在自己電腦離線使用

Windows：雙擊 `start-story.bat`（直接開啟 index.html 時 YouTube 會拒絕播放）。

## 每日自動更新

- 每天清晨（曼谷時間）由排程任務依 `scripts/DAILY_TASK.md` 選片、出題，更新 `daily.json` 與 `used.json` 後推送
- `python3 scripts/validate.py`：推送前檢查 `daily.json` 格式
